# Phase 4 — Cinematic Navigation

Phase 4 continues directly from Phase 3 on the single `phase-4` branch.

## Scope

- Cinematic camera movement and path tracing
- Scroll-driven navigation through the network
- Deeper Experience, Skills, Philosophy, About and Contact flows
- Stronger active-path feedback and depth cues
- Responsive touch interaction
- Accessibility and reduced-motion support
- Performance and CI verification

## Branch rule

All Phase 4 implementation, fixes, UI changes, interaction changes, and polish stay on **`phase-4`**.

No additional Phase 4 branches should be created.

## Current baseline

The branch starts from the completed Phase 3 project state and currently contains the Phase 4 cinematic navigation layer.
