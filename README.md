# Flow Portfolio

Interactive portfolio website built around a visual flow/network interface.

Development is managed directly through GitHub. No local build workflow is required.

## Phase One

The first phase establishes the interactive network foundation:
- Central Nayan Asati node
- Portfolio section nodes
- Project expansion
- Drag/pan interaction
- Scroll-to-zoom
- Responsive layout

Further interaction, motion, case studies, and visual polish will be added phase-by-phase.
