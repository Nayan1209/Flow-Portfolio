# Flow Portfolio

An interactive portfolio built as a visual network rather than a traditional page-by-page portfolio.

## Phase One — Interactive Network Foundation

Implemented directly through GitHub; no local build workflow is required.

### Included
- Next.js + TypeScript foundation
- Full-screen responsive network canvas
- Central **NAYAN ASATI** node
- Connected Projects, Experience, Skills, Philosophy, Contact and About nodes
- Projects branch expansion
- JobPilot AI, Photography and Windows UI project nodes
- Hover interaction and active connection highlighting
- Click-to-expand navigation
- Drag / pan camera movement
- Scroll-to-zoom
- Keyboard controls and Escape reset
- Desktop and mobile responsive layout
- GitHub Actions build verification
